# iOS status

`AppTemplate` is the upstream llama.cpp SwiftUI example, not a completed iOS
version of Nova. It has not been adapted to use this project's model,
prompt, or chat-history behavior, and it has not been built or tested here.
Do not present it as a tested iOS release.

The sample README describes its expected Xcode and llama.cpp framework setup.
It requires macOS and Xcode; a Windows machine cannot build or sign an iOS app.
An installable release also requires Apple signing and provisioning.

The included sample has its own MIT license in `AppTemplate/LICENSE`. No claim
is made that the chatbot's desktop or Android source is part of that license.
